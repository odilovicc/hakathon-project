# ТЗ: «Кубышка» — трекер денег с питомцем, который живёт на твоих накоплениях

## 0. Суть продукта в трёх предложениях

Пользователь записывает доходы и расходы, ставит цель накопления и каждый день делает короткий «отчёт дня». На его накоплениях живёт питомец: ежедневные отчёты его кормят и задают настроение, рост накоплений открывает ему костюмы и эволюцию. Музей несделанных покупок и подписки помогают заметить экономию и записать её в цель после фактического откладывания денег.

Единственный персонаж, единая экономика. Никаких отдельных «огоньков» и «серий»: огонёк стал аурой питомца.

## 1. Нейминг

Основное название: **Кубышка**. Старое русское слово для горшка, в котором прятали деньги. Понятно без объяснений, тёплое, не похоже на «Fin», «Pay», «Money» из стора. Домен-кандидаты: kubyshka.app, kubyshka.money.

Питомец: вид существа называется **кубыш**. Это маленькое округлое существо, которое живёт внутри кубышки. Имя питомцу даёт пользователь при онбординге.

Запасные названия, если «Кубышка» не подойдёт: **Нычка** (дерзко, сленг), **Сурок** (запасливый зверь, хороший маскот).

Слоган для лендинга: «Деньги, которые ты не потратил, кого-то кормят».

## 2. Стек и архитектура

**Монорепозиторий** с npm workspaces:

```
kubyshka/
  package.json            # workspaces: client, server; скрипты dev/build/seed через concurrently
  client/                 # React 18 + Vite + TypeScript
  server/                 # Express + TypeScript + better-sqlite3
  README.md
```

**Клиент:** React 18, Vite, TypeScript, Tailwind CSS v4, React Router v7, TanStack Query для серверных данных, Zustand для UI-состояния (открытые модалки, выбранный питомец-вид), Framer Motion для анимаций, canvas-confetti для праздников, Phosphor Icons (duotone), date-fns, Recharts для графиков.

**Сервер:** Express 5, TypeScript, better-sqlite3 с миграциями на чистом SQL (папка `server/migrations`, применяются при старте), zod для валидации тел запросов, bcrypt для паролей, JWT в httpOnly cookie, cookie-parser, cors только для localhost в dev. Файл БД: `server/data/kubyshka.db`. Скрипт `npm run seed` создаёт демо-пользователя с операциями, целью, музеем и питомцем.

**Деньги храним в целых** (минимальные единицы валюты, bigint-safe integer). Валюта у пользователя одна, выбирается при регистрации: ₽, ₸, сум, $. Форматирование через Intl.NumberFormat.

**Без внешних платных API.** Учёт и накопления работают без подключения банков и внешних каталогов.

## 3. Дизайн-система

### 3.1 Что запрещено

Шрифты Inter, Roboto, JetBrains Mono, Fira Code, Space Grotesk. Фиолетово-синий градиент на hero. Глассморфизм. Эмодзи вместо иконок. Иконка «✨» и слово «ИИ» в интерфейсе. Фразы вроде «Добро пожаловать в будущее финансов». Одинаковые карточки-плитки 3 в ряд с иконкой-заголовком-текстом на весь лендинг. Тёмно-синий как основной цвет.

### 3.2 Шрифты

Оба с Google Fonts, оба с кириллицей:

- **Unbounded** — заголовки, крупные цифры, название. Вес 500–800. Геометричный, широкий, запоминается.
- **Onest** — весь остальной текст. Вес 400–600. Для чисел включить `font-variant-numeric: tabular-nums`.

Моноширинный шрифт не используется нигде.

### 3.4 Форма

Скругления: карточки 24px, кнопки 999px (пилюли), инпуты 14px. Тени мягкие и тёплые: `0 10px 30px -12px rgba(43,31,46,0.18)`. Основные кнопки пилюли с заливкой clay, текст кремовый. Вторичные с обводкой line. Крупные цифры (баланс, безопасная сумма) в Unbounded 48–64px, как в референсах. Макет лендинга асимметричный: текст слева на 5 колонок, питомец справа большой и выходит за край карточки.

### 3.5 Иконки

Phosphor Icons, стиль duotone, вторичная заливка в цвет rose или iris-soft.

## 4. Анимации

Библиотека Framer Motion. Правила:

- Переходы между страницами через `AnimatePresence`: уходящая страница `opacity 0, y 8`, приходящая `opacity 1, y 0`, 260 мс, easing `[0.22, 1, 0.36, 1]`.
- Списки транзакций и карточки появляются со stagger 40 мс.
- Числа баланса и экономии считаются вверх через `useSpring` с `animate`, 600 мс.
- Прогресс цели — spring (`stiffness 120, damping 20`).
- Модалки: scale от 0.96, opacity, 200 мс. Фон затемняется plum с 40%.
- Шаги онбординга: горизонтальный слайд, направление зависит от «вперёд/назад».
- Питомец: постоянное «дыхание» (scale 1 → 1.03, 3 с, CSS keyframes), моргание раз в 4–7 с случайно, при кормлении подпрыгивает (spring), при открытии костюма вспышка + confetti в цветах clay/iris/honey.
- Аура питомца — радиальный градиент за ним, цвет меняется по тиру через transition 1.2 с.
- Hover карточек: `y -2`, усиление тени, 180 мс.
- Обязательно уважать `prefers-reduced-motion`: все движения заменяются на fade.

## 7. Экраны

### 7.1 Лендинг `/`

1. Шапка: логотип-слово «Кубышка» в Unbounded, ссылки «Как работает», «Твоя цель», кнопки «Войти» (вторичная) и «Начать» (clay).
2. Hero: слева заголовок «Копи так, будто кормишь кого-то живого», подзаголовок про отчёт дня за 10 секунд, кнопка «Завести кубыша». Справа большой анимированный кубыш на фоне rose-пятна с аурой. Под hero три карточки-«чипа» в стиле первого референса: «Отчёт дня», «Музей несовершённых покупок», «Подписки».
3. «Как работает» в три шага, числа крупные в Unbounded, не плитки, а вертикальная лента с линией слева.
4. Блок про питомца: раскадровка одного и того же кубыша в 4 настроениях и 3 стадиях.
5. Блок экономии: пример ненужной подписки и её стоимости за год.
6. Тарифы: две колонки. «Бесплатно» со всем основным. «Плюс» с пометкой «скоро»: семейный режим, экспорт, расширенная аналитика. Без цен.
7. FAQ аккордеоном из 5 вопросов, с анимацией высоты.
8. Футер.

### 7.2 Авторизация `/login`, `/register`

Одна карточка по центру, кубыш выглядывает сверху карточки. Поля: email, пароль, имя и валюта при регистрации. Ошибки под полями, не алертами. После регистрации редирект на онбординг.

### 7.3 Онбординг `/onboarding`

Шесть шагов, каждый на своём экране, прогресс-полоска сверху, кнопка «Назад». Один вопрос на экран, крупный заголовок.

1. Доход в месяц. Слайдер с диапазонами и полем для точной цифры.
2. Сколько обычно уходит в месяц. Четыре карточки-диапазона: «меньше половины», «около половины», «почти всё», «больше, чем зарабатываю».
3. Долги. Да/нет, если да, диапазон суммы.
4. Подушка. «Нет», «на месяц», «на 3 месяца», «больше».
5. Цель. Название, сумма, желаемая дата. Показываем сразу: «это по X в месяц».
6. День зарплаты и график работы: день месяца, часов в день, дней в месяц. Объяснить: «так мы переведём траты в часы твоей жизни».

Финал: экран рождения кубыша. Яйцо-кубышка трескается (анимация), пользователь даёт имя. Кнопка «В кабинет».

### 7.4 Кабинет `/app` (layout с боковой навигацией на десктопе и нижней на мобильном)

Разделы: Сегодня, Операции, Цель и кубыш, Музей, Подписки, Настройки.

**Сегодня `/app`:**
- Крупная цифра «Можно потратить сегодня» = (доход − обязательные регулярные − взнос на цель − уже потрачено в этом периоде) / дней до зарплаты. Цвет цифры: moss, honey при < 30% от нормы, brick при отрицательной.
- Карточка кубыша: настроение, аура, кнопка «Отчёт дня», если сегодня не сделан. Если сделан, фраза от кубыша.
- «Отчёт дня» — модалка на 10 секунд: «Сколько потратил сегодня?» (сумма, можно 0), «Как ощущение?» (три пиктограммы: спокойно, нормально, сорвался). Сохраняет чек-ин, создаёт транзакцию «расход за день» если сумма > 0 и нет других записей за день, кормит питомца.
- Быстрое добавление операции: кнопка-пилюля «+ Операция», модалка с переключателем доход/расход, суммой, категорией-чипами, заметкой, датой.
- График расходов по дням за период до зарплаты (столбики, clay), линия «средний безопасный уровень».
- Топ-3 категории за период.

**Операции `/app/transactions`:** список по дням, фильтры по типу, категории, поиску, диапазону дат. У каждого расхода вторая строка: «≈ 3 ч 20 мин твоей работы». Свайп/иконка для удаления, клик для редактирования.

В форме операции доступны 27 категорий расходов, полный список с поиском и создание личной категории. При обновлении базы прежние операции и категории сохраняются.

**Цель и кубыш `/app/goal`:**
- Большой кубыш в текущих костюмах, аура по тиру, имя, стадия.
- Прогресс цели, кнопки «Пополнить» и «Снять».
- Карточка «Будущий ты»: при текущем темпе цель будет через N месяцев; если добавлять +10% в месяц, то через M. Два маленьких силуэта кубыша: нынешний и на финише.
- Гардероб: сетка костюмов по слотам с порогами открытия. Закрытые серые с замком и «откроется на 45%». Снятые за вывод денег подсвечены honey с подписью «в сундуке, вернётся на 60%».
- Лента событий цели.

**Музей `/app/museum`:**
- Кнопка «Удержался от покупки». Модалка: что хотел, сколько стоило, категория. После сохранения предложение «Перевести эту сумму в копилку?» одной кнопкой.
- Галерея экспонатов как музейные таблички: название, цена, дата, «≈ часов жизни сохранено». Сверху общая сумма: «В музее лежит 184 000, это 2 месяца взносов в цель».

**Подписки `/app/subscriptions`:**
- Авто-детект: расход с тем же названием и суммой ±5% в двух и более месяцах подряд помечается как подписка.
- Список: название, сумма в месяц, статус. Кнопка «Не пользуюсь» переводит в unused и показывает сумму экономии за год. Кнопка «Отменил» убирает из расчётов и предлагает перевести месячную сумму в копилку.

**Настройки:** имя, валюта, тема, день зарплаты, график работы, удалить аккаунт, выйти.

## 8. Логика питомца

**Настроение (mood 0–100):** чек-ин +25, пропущенный день −15 ночью (крон при первом запросе пользователя, не фоновый процесс). Диапазоны: 0–25 сонный, 26–50 спокойный, 51–80 довольный, 81–100 сияющий. Каждый диапазон меняет позу, глаза и реплики.

**Дни заботы (care_days):** считается количество чек-инов, пропуск не обнуляет, а замораживает. Тиры ауры по care_days: 0–9 уголёк (clay), 10–19 янтарь (honey), 20–29 роза (rose насыщеннее), 30–39 ирис (iris), 40–59 северное сияние (градиент iris → moss), 60+ золото. Смена тира — короткая сцена с confetti.

**Костюмы по проценту цели:** 15% шарф, 30% шапка, 45% очки, 60% домик-фон, 75% плащ, 90% корона, 100% эволюция в стадию выше и праздничный экран. Стадии 1–3 меняют размер и форму кубыша.

**Снятие с цели:** если процент опустился ниже порога костюма, костюм получает `is_locked_back = true`, визуально уходит в сундук с анимацией, вернётся при повторном достижении порога. Это главный «честный» элемент: решение видно на персонаже.

**Корм от экономии:** запись экономии из отменённых подписок или музея в копилку даёт +10 к настроению сверх чек-ина, кубыш показывает реплику про еду.

**Реплики:** 40–60 коротких фраз в файле `client/src/pet/lines.ts`, сгруппированы по настроению и событиям. Тон живой, без «молодец, так держать». Примеры: «Ты не купил наушники. Я бы тоже не купил», «Сегодня тихо. Мне нравится тихо».

## 9. Визуал кубыша

SVG-компонент `<Kubysh mood stage costumes auraTier size />`, собранный из слоёв: аура, тело, лицо (глаза и рот зависят от mood), слои костюмов по слотам. Тело — мягкая капля с «крышкой» кубышки сверху, цвет тела rose/clay в зависимости от стадии, глаза крупные с бликом. Никаких растровых 3D-картинок: всё SVG, чтобы анимировать слои. Отдельно 4 размера: 48 (навигация), 120 (карточка), 240 (цель), 360 (лендинг).

## 11. Качество

- TypeScript strict на обеих сторонах, общие типы в `shared/` через path alias.
- ESLint + Prettier.
- Тесты на сервере (vitest): расчёт безопасной суммы, детект подписок, миграции категорий, логика костюмов при снятии.
- Lighthouse лендинга: performance и accessibility не ниже 90. Все интерактивные элементы с фокус-состоянием (обводка clay 2px offset 2px).
- Адаптив: 360px и выше, нижняя навигация на мобильном, боковая от 1024px.
- README с запуском: `npm install`, `npm run seed`, `npm run dev`, порты 5173 и 3001.
